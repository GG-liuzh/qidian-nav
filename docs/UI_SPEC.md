# 栖点 · 视觉与界面规范

版本：v1.1 · 2026-09-14

首页与搜索铺满侧栏外的可用屏幕宽度；1800px 以上可显示四列、2400px 以上五列。公开页无需登录，个人与部门共用同一套资源卡片，游客卡片只提供链接与说明。

## 1. 视觉方向

**明亮、安静、有秩序的工作台。** 使用暖白底色、深墨色标题、松绿色主操作，保留适当留白，同时让一屏可以看到足够多的系统。

产品暂名“栖点”，含义是把分散的入口安放到固定位置。标识采用简洁的方形与路径几何，导航图标保持同一笔画风格。视觉不依赖背景大图、动效或在线字体。

首页的阅读顺序是：搜索 → 自己固定的具体入口 → 环境与业务筛选 → 系统卡片。运维指标、密码管理说明和管理表格不抢占首页。

## 2. 布局

| 区域 | 桌面规格 | 内容 |
| --- | --- | --- |
| 左侧导航 | 224px；宽屏固定，窄屏折叠 | 标识、主要视图、业务线、空间设置、成员 |
| 顶部路径栏 | 72px | 空间 / 当前视图、主题、帮助 |
| 正文 | 填满侧栏外的可用宽度，左右 13–38px 随屏幕调整 | 标题、搜索、快捷入口、资源网格 |
| 搜索框 | 填满正文宽度，高 52px | 搜索图标、输入、清空、快捷键提示 |
| 快捷入口 | 3–4 列，窄屏自动换行 | 系统名称、明确环境、图标 |
| 工具条 | 可换行 | 业务范围、环境分段按钮、排序、布局切换 |
| 系统卡片 | 最小约 280px，常规 300–380px | 系统信息、环境入口、账号操作 |
| 抽屉 | 480px，移动端全屏 | 详情 / 账号 / 添加 / 编辑 |

卡片整体不作为模糊的跳转热区。系统名称打开详情，环境按钮打开相应地址，账号按钮打开账号面板，收藏按钮只改变本人收藏状态。

## 3. 色彩与字体

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 页面底色 | `#F6F7F4` | `#121916` | 正文背景 |
| 面板底色 | `#FFFFFF` | `#1B2420` | 卡片、抽屉 |
| 次级底色 | `#EDF1EC` | `#25312B` | 输入、次级操作 |
| 主文字 | `#202B25` | `#E8EEE9` | 标题与主要信息 |
| 次级文字 | `#647067` | `#A6B5AB` | 描述、辅助信息 |
| 边框 | `#E0E6DF` | `#35433A` | 结构分隔 |
| 主色 | `#2E5D48` | `#9DD3B4` | 主按钮、选中状态 |
| 开发 | `#4367A6` / `#EDF2FA` | 适配深色底 | 开发标记 |
| 测试 | `#2B6A50` / `#EAF3ED` | 适配深色底 | 测试标记 |
| 生产 | `#97600D` / `#FCF3E3` | 适配深色底 | 生产标记 |
| 错误 | `#AF3E3E` | `#F1A0A0` | 错误与危险操作 |

- 字体：系统字体优先，中文使用 PingFang SC / Microsoft YaHei / Noto Sans CJK；英文使用系统无衬线。地址和快捷键使用系统等宽字体。
- 页面标题 30–32px，区块标题 18–20px，卡片标题 16px，正文 14px，次级标记 12–13px。
- 常规字重 400/500，主要标题 600/700。行高 1.5–1.7。
- 4px 间距基线；主要间距 8 / 12 / 16 / 24 / 32px。
- 控件圆角 8–10px，卡片 14–16px，抽屉内分区 12px；阴影非常轻，优先用边框建立层次。
- 主题支持浅色、深色和跟随系统；环境文字不因主题或品牌色变化而消失。

## 4. 首页组件

### 左导航

公开首页放分类目录和登录入口。登录后显示“公开导航”“我的收藏”“最近访问”“个人导航”，有部门资格时再显示“团队导航”。业务线在下方分组显示，当前项使用浅绿背景与深绿文字。底部是空间设置和当前用户。

用户切到个人空间后，业务线列表替换成个人分组，不再显示团队维护入口。小屏使用可关闭的侧栏，带遮罩和键盘焦点管理。

### 搜索

搜索区使用真实输入框和明确 label。占位提示为“搜索系统、环境、标签或域名…”，右侧显示 Ctrl K 或 ⌘ K。输入时更新结果数量，搜索建议可以按键盘选择；加载、无结果和失败各有状态。

首次默认不显示搜索建议大面板；聚焦后可呈现本人最近访问和常用入口。搜索不会查询密码或账号备注。

### 快捷入口

快捷项固定到具体入口。例如“订单中心 / 测试”，不会受下方全局环境筛选影响。使用细边框的横向小卡，保留名称、环境文字及外链图标。支持用户自己排序和移除。

### 系统卡片

```text
[系统图标] 订单中心                  [收藏]
           交易平台 · OMS

订单查询、履约管理与售后处理。

[开发 DEV ↗] [测试 TEST ↗] [生产 PROD ↗]

─────────────────────────────────────
[钥匙] 共享账号               林知夏 · [编辑]
```

- 账号数量仅在有相应权限时显示；没有账号时可以显示“使用说明”，或不展示账号操作。
- 卡片网格内保持操作基线对齐，但不强行裁掉关键描述；长标题和长标签使用明确换行策略。
- 悬停只做约 2px 的位移与轻微边框强调，避免大范围发光。
- 生产环境始终标记 PROD，使用低饱和琥珀色；它不是错误状态，不使用大红警告条。
- 负责人可进入联系方式或维护信息，显示姓名文字，不只靠头像识别。

### 通用书签

接口文档、知识库等资源使用更轻的紧凑行或小卡。显示来源域名、归属及收藏；不强行生成三个环境按钮。

## 5. 账号面板

顶部是系统名、业务线和关闭按钮。环境以分段按钮切换，下一行显示当前完整域名及“打开系统”。中部按账号用途分组。

每份账号包含：用途标题、状态、用户名、密码、复制操作、使用说明、更新时间与负责人。用户名与密码各有明确的“复制用户名”“复制密码”，密码旁提供“显示 / 隐藏”。复制成功使用短时图标与文字反馈，同时通过 aria-live 宣告。

“账号不可用”和“申请权限”放在对应位置，不使用笼统的全局报错入口。过期状态用文字说明，并隐藏不可执行的取密按钮。

账号面板不自动复制、不自动向目标系统提交登录表单，也不把密码拼接到跳转 URL。

## 6. 表单

- 必填项只包含保存所必需的信息；标签与备注可以稍后补充。
- 系统的每个环境是一行明确配置：环境选择 / 地址输入 / 删除。能继续添加自定义环境。
- 真实 URL 以完整文本显示，允许横向滚动输入但不让整个页面溢出。
- 错误显示在对应字段下方，顶部只总结需要修复的项数；提交后定位第一个错误。
- 保存时防重复提交。成功关闭抽屉并定位新卡片，筛选导致不可见时提供“查看新链接”。
- 删除只对产生影响的操作进行确认，清楚说明回收站和恢复期限。普通环境跳转不反复弹确认窗。

## 7. 动效、响应式与无障碍

| 场景 | 规则 |
| --- | --- |
| 普通反馈 | 120–160ms，颜色 / 阴影变化 |
| 抽屉 | 180–220ms，尊重减少动态效果设置 |
| 通知 | 约 2.5 秒成功提示；错误消息保留到操作或关闭 |
| ≥ 1280px | 左导航 + 三列系统卡片 |
| 900–1279px | 较窄导航或折叠导航 + 两列卡片 |
| 640–899px | 折叠导航，依可用宽度一至两列 |
| < 640px | 单列；搜索快捷键提示隐藏；筛选换行；抽屉全屏 |
| 触控 | 主要点击区域至少 44 × 44px，操作不依赖 hover |
| 键盘 | 可见焦点；Tab 顺序与视觉顺序一致；弹层焦点限制在内部 |
| 弹层关闭 | Esc 关闭顶层并回到原触发按钮；未保存表单先处理草稿 |
| 屏幕阅读器 | 地标、标题、表单标签、状态播报完整；图标装饰隐藏 |

静态原型允许先验证结构和主要交互，正式开发必须使用真实用户状态、权限与加载过程再次检查可访问性。

## 8. 评审方式

先看首页是否能快速识别“系统 + 环境”；再点击共享账号检查是否始终知道自己在复制哪个环境的账号；最后体验新增系统是否需要重复填写过多信息。

视觉可以调整主色、密度和品牌名，产品结构保持一致。界面稿提供明暗主题和卡片 / 列表切换，帮助比较实际使用感受。

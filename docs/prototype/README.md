# 可交互界面稿

这是保留的静态视觉与交互样例，所有团队、成员、系统地址和账号均为虚构数据。正式应用已在 `frontend` / `backend` 实现，使用 `start.ps1` 启动并访问 4180；本文件的“尚未实现”仅指这个静态原型。

## 可以体验

- 团队导航、我的收藏、最近访问、个人空间与业务线切换。
- 搜索名称、示例别名、拼音、标签、域名；中文环境词与系统词可以组合搜索。
- 开发 / 测试 / 生产筛选、卡片 / 列表、浅色 / 深色主题。
- 系统和通用书签收藏；收藏数量同步更新。
- 账号面板切换环境，显示 / 隐藏演示密码，分别复制用户名或密码。
- 添加系统或普通书签；编辑元数据与环境地址，并可添加虚构共享账号。修改仅在本页面内存中保存。
- 修改入口域名后，原有演示账号停止显示，体现账号绑定需要重新确认的规则。
- 新增 / 编辑表单校验、未保存关闭提示、无结果状态与小屏布局。
- Ctrl/Cmd + K 或 / 聚焦搜索，Esc 关闭顶层面板。

## 尚未实现

真实登录、成员授权、凭据加密、后端持久化、导入导出执行、自定义环境配置、维护流程与服务器自动检测。这些功能在设计文档中定义，原型对应入口展示设计说明，不模拟正式完成结果。

演示账号在 JavaScript 中明文定义，只用于展示交互，不代表正式的凭据存储方式。正式版本的方案是服务端加密、按需授权获取，参见 `../IMPLEMENTATION_PLAN.md`。

环境示例地址使用保留的 `.example` 域名，点击会展示准确的目标和环境，不访问任何实际企业系统。使用自己添加的 HTTP/HTTPS 链接时会正常在新标签页打开，原页面记录本次演示访问。

## 查看

在 `qidian-nav` 目录执行：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory docs/prototype
```

然后访问 `http://127.0.0.1:4173`。原型不发送 API 请求、不使用任何第三方资源，也不保存浏览器长期数据。页面刷新后恢复初始演示状态。

可以直接打开 `index.html`；若浏览器不允许剪贴板操作，页面会提供手动选取方式。通过 localhost 预览通常能正常使用 Clipboard API。

## 本轮验证记录

2026-09-14，使用本机 Playwright + Chromium 对 localhost 原型进行串行检查：

- 35 项主要交互检查通过，覆盖检索、环境筛选、收藏、账号环境绑定、显示与隐藏、表单校验、新增与编辑、草稿保留、个人内容切换、链接 HTML 转义和最近访问。
- 复制成功与失败分支使用剪贴板测试替身验证，不读写用户的系统剪贴板；20 秒隐藏使用浏览器时钟快进验证。真实浏览器复制仍取决于 HTTPS / localhost 与浏览器授权。
- 在 320、390、768、1024、1440、1920px 六个宽度检查卡片 / 列表、账号面板、编辑表单、主题和导航；动画结束后均无页面及关键控件的横向溢出。
- 手机尺寸采用触控模拟，检查侧栏开合与关闭后背景恢复；桌面检查搜索快捷键与 Esc；抽屉检查焦点仍在面板内。
- 检查期间无 JavaScript 运行错误。以上仅为原型交互与布局验证，不代替正式后端的权限、加密、持久化或部署测试。

原型不提供完整的账号轮换、删除资源、导入、权限审批与自动检测流程；这些仍按产品设计分阶段实现。自定义环境、个人快捷入口排序和跟随系统主题也属于后续正式功能，当前原型只呈现默认环境与手动主题切换。
